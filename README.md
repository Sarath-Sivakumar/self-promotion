# Sarath Sivakumar Portfolio

Professional personal portfolio website for Sarath Sivakumar, AI Systems Engineer.

## Tech Stack

- Vue 3 (Composition API, `<script setup>`)
- Vite
- TypeScript
- Tailwind CSS
- Vue Router
- Lucide Vue Next

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Deployment

Designed for seamless deployment to Vercel (includes `vercel.json` SPA rewrite configuration).
